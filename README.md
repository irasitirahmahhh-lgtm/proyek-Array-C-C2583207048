# Deskripsi
Aplikasi console menggunakan bahasa C untuk mengelola produk kantin, stok, transaksi pembelian beberapa produk, pencarian, pengurutan, dan laporan penjualan. Data disimpan di memori selama program berjalan.
Fitur
1.	Melihat daftar nama produk, harga, stok, dan jumlah terjual.
2.	Menambahkan produk (maksimal 50 produk).
3.	Mengubah harga dan/atau stok produk.
4.	Transaksi beberapa produk dalam satu keranjang.
5.	Menambah stok.
6.	Mencari produk berdasarkan nama/kata kunci.
7.	Mengurutkan harga dari termurah atau jumlah terjual dari terbanyak.
8.	Laporan jumlah setiap produk terjual, total unit, pendapatan, dan produk terlaris.
9.	Memeriksa produk dengan stok kurang dari 5.
10.	Validasi input dan penanganan kesalahan.
